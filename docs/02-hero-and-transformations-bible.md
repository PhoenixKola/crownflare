## Four clean form reference requirements

Prepare four **solid-fill black silhouettes** on same ground line at **48/60/72 logical px tests**, shown side-by-side and inside the actual game chamber with VFX completely off. Base human courier; Dawnrush upright pressure-band muscular posture; Stormhalo collar fins and split orbit; Eclipse Warden visibly taller/hovering plated shape with new mask/mantle and controlled detached halo blades. Any pair confusable in motion is REVISE, not pass.

## Identity retention vs metamorphosis

Keep tiny recognizable motifs across Iona's eyes/pressure-split geometry and emotion, not original humanoid exact body. Final form is a fully altered physical entity with bespoke action animations; no recolors, upscales, silhouette masks or static aura overlays can replace its full sprites.

## Gate order

1. Tiny form silhouette comparison at actual scale + background contrast.
2. Owner chooses one canonical Iona master — record file and checksum.
3. Real in-engine base idle/action and left/right reviewed.
4. Full animation system proven before mass frames.
5. Each form separately approved for clean silhouette, movement/combat, living aura, bespoke SFX, UI and ordinary-run integration.
