# Project Crownflare — World, Rooms & Roguelite Design

## Intended full gameplay loop

Title → safe Spindle hub → run start / choice → curated branching chamber → platform traversal and hand-play combat → reward / repair / event → elite / region boss → further choices → final confrontation or defeat → results → metaprogression / changes to hub. Target **25–35 minute mature run**; obtain real playtest pacing data. B00 contains one disposable fixed test chamber; none of this meta loop is implemented.

## Chamber production rules

Handcraft memorable platform/sighting/spawn chunks with entry/exit anchors, readable collision, hazard spacing, foreground clarity and animation layers. Generate run sequences from constrained seeded graphs, not arbitrary noisy rooms. Each region needs its own palette, parallax language, interactive set pieces and rhythmic reward beats. Design platforms around the **actual locked hero movement**, not assumptions about future grapples/double jumps.

## Provisional first-release scope (not B00 authorization)

Two contrasting regions plus final arena; about 6 distinct regular enemy archetypes and 2 elite variations, 2 regional bosses and 1 final boss; room pool sufficient for strategic branches, not faux infinite procedural content. Small curated set of upgrades (strikes, mobility, Resonance, risk/reward, utility, form-specific). Explain stacking, caps, exclusivity and resulting animation/VFX. Every enemy needs silhouette, authored tells, stagger/KO, meaningful AI, original sound and counterplay against all four forms.

## Narrative tone

The Spindle's day/night collapse is a personal wound for courier Iona. Each escalating form offers power but a cost and changes how characters respond. Tell the main story with environment, compact hub dialogues, a few rival/boss conversations and concise end-state. Finish one coherent hero arc; do not imply DLC characters needed for the ending.

## Content gates

No additional rooms until one complete B04 combat vertical slice is visual-approved. B08 enemies only after forms, B09 room assembly after enemies, B10 bosses only when telegraph readability and camera consistency exist. Variations must create playstyle diversity, not clone sprites with color swaps.
