CROWNFLARE 1.0.0 — PRIVATE WINDOWS PC CANDIDATE

RUN
1. Extract the entire Crownflare-v1.0.0-windows-x64.zip archive.
2. Open the extracted folder and double-click Crownflare.exe.

REQUIREMENTS
Windows 10 or 11, 64-bit Intel/AMD PC. No Node.js installation or internet
connection is needed to play after extraction. The game does not download
content or install updates.

Windows may show its standard SmartScreen notice because this private build is
not code-signed. Do not disable SmartScreen; choose Run anyway only if you trust
the person who gave you this ZIP.

WINDOW AND DISPLAY
The app opens fullscreen. Press F11 to switch to a resizable window or return to
fullscreen. Pixel Perfect scaling keeps game pixels crisp and preserves the
16:9 picture; other monitor ratios show side or top bars. Open Controls /
Accessibility to choose Fit for fractional scaling. The selected display mode,
reduced-motion, sound, and control settings are saved between launches.

CONTROLS
A / D: move       Space: jump       Shift: dodge
J: light attack   K: heavy attack   Q: Resonance special
R: Dawnrush       F: Dawnfall       E: interact
Escape: pause

Standard-mapped gamepads are supported. Open Controls / Accessibility to view
or remap buttons, adjust stick dead zone, and enable rumble.

SAVES AND BACKUPS
Desktop saves and settings are stored under:
%APPDATA%\Crownflare\
Close Crownflare before backing up that whole folder. Replacing the folder can
replace progress, so keep a separate backup. Browser saves are separate and are
not imported into this desktop copy. The first desktop launch starts its own
save; it never reads or overwrites browser-profile data.

RELEASE STATUS
This is a private v1.0.0 candidate, not a public release. The completed-route
automated baseline is about 3 minutes; the owner has accepted the compact game
scope. The build is unsigned and may show SmartScreen. Public name clearance,
physical gamepad review, human audio listening, and owner approval of the final
executable remain separate release decisions.
