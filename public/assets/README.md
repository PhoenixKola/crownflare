# B00 asset namespace — deliberately no production sprite
This directory will hold only exported, approved runtime assets. B00 uses Phaser rectangles strictly as **programmer geometry**, not a hero concept, style standard, or approved character art.
Planned directories by approved form: `characters/iona/base`, `dawnrush`, `stormhalo`, `eclipse-warden`, plus enemies, bosses, environments, vfx, ui, audio. Create folders when assets exist; don't commit empty trees.
