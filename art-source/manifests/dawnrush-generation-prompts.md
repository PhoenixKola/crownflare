The image tool exposed a generated file ID and local output path, but did not expose a model/version field in its result. The original calls are summarized below as submitted-art direction; the exact prompt text was not retained by the tool transcript after compaction, so this is not presented as a verbatim prompt log.

The transparent source sheets are kept unchanged. `tools/art-export/build-dawnrush.py` thresholds generated fringe alpha, extracts the cells, scales the locomotion and combat poses with one shared factor to the 128×80 / 64×80-foot-pivot convention, mirrors left-facing art, and produces the manifest and runtime contact sheets. No hand-drawn substitute sprites are used in gameplay.
