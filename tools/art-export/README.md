# Future original art export — reserved for B01

Do not mass-generate frames during B00. The current concept board is provisional and non-runtime.

B01 will lock one Iona canonical master by owner approval; derived animation frames must preserve a consistent pixel-grid, proportions, pivots and frame hashes. Exports will have SHA256 provenance and a manifest mapping every actual source PNG, animation frame, audio/VFX event and atlas rectangle to runtime IDs. The export tooling must be reproducible on Node/TypeScript and image tools available to Codex; Blender is not required.
